# Высококонверсионный Landing Page: Компания «АТМОС» & Федерация гонок дронов Ростовской области

Интерактивный веб-сервис для открытого мастер-класса и дня открытых дверей по FPV-дрон-рейсингу в Ростове-на-Дону.

---

## 🚀 Основной стек технологий
- **Фреймворк:** Next.js 15 (App Router, React 19, TypeScript)
- **Стилизация:** Tailwind CSS (фирменная цветовая палитра «Атмос» `#0A0A0C`, `#FF5500`, неоновые свечения, HUD-разметка)
- **Интерактивная скролл-анимация:** Canvas Dual Racing Drones (два FPV-дрона «Атмос» и «Федерация» с неоновыми шлейфами, поочередными обгонами, тангажом/креном и idle-парением со стабильными 60 FPS)
- **База данных:** SQLite с транзакциями `BEGIN IMMEDIATE` и параметризованными запросами (защита от SQL-инъекций и race conditions)
- **Валидация:** Zod, строгая санитизация XSS, маска телефона `+7 (999) 999-22-11` и Honeypot-защита от спам-ботов
- **Экспорт для бухгалтерии:** Модуль `xlsx` с генерацией файла `.xlsx` в 1 клик
- **Юридическая чистота (152-ФЗ РФ):** Модальные окна согласия на обработку ПД и политики конфиденциальности, cookie-баннер, дисклеймер защитной сетки

---

## ⚡ Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сервис будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

### 3. Сборка и запуск в production
```bash
npm run build
npm run start
```

## 🎯 Архитектура бронирования (Smart Booking Engine)

Система реализует жесткий контроль емкости слотов согласно регламенту безопасности полетов:
- **Слоты ДО 14:00** (`10:00 - 11:00`, `11:00 - 12:00`, `12:00 - 13:00`, `13:00 - 14:00`):
  - Лимит: **строго 10 мест**.
- **Слоты ПОСЛЕ 14:00** (`14:00 - 15:00`, `15:00 - 16:00`, `16:00 - 17:00`, `17:00 - 18:00`):
  - Лимит: **строго 5 мест**.
- **Динамические статусы:**
  - `Осталось мест: X из 10 (или 5)`
  - Бейдж `«Мало мест»` при остатке 1-2 мест
  - Автоматическая блокировка слота `«Мест нет»` при исчерпании лимита
  - Предупреждение для несовершеннолетних: если возраст `< 18` лет, отображается требование присутствия родителей.

## 📊 Решение для бухгалтера и администрации

Бухгалтеру не требуются технические навыки. Доступны два способа выгрузки:

### Способ 1: Панель администратора
1. Перейдите по адресу: [http://localhost:3000/admin](http://localhost:3000/admin)
2. Введите ключ доступа: `atmos2025` (настраивается в `.env.local` через `ADMIN_SECRET_KEY`)
3. Нажмите большую зеленую кнопку: **«📥 Скачать все записи в Excel (.xlsx)»**
4. Доступны фильтры по датам проведения и поиск участников по ФИО или телефону.

### Способ 2: Прямая ссылка для скачивания
Бухгалтер может просто кликнуть по ссылке в браузере или закладках:
```
http://localhost:3000/api/admin/export?key=atmos2025
```
Браузер моментально скачает файл `atmos_bookings_all_YYYY-MM-DD.xlsx`.

### Способ 3: Автоматическая отправка в Яндекс Таблицы / Google Sheets
В файле `.env.local` укажите:
```env
WEBHOOK_SHEETS_URL=https://script.google.com/macros/s/.../exec
```
Каждая новая успешная заявка будет мгновенно отправляться в облачную таблицу.

## 🛡️ Безопасность и соответствие 152-ФЗ РФ
1. **Защита от Race Conditions:** Проверка доступности мест и создание записи происходят внутри единой блокирующей транзакции SQLite. Невозможно записать 11-го человека на утренний слот или 6-го на вечерний.
2. **Защита от SQL-инъекций:** Исключительно параметризованные Prepared Statements.
3. **Локализация:** Серверы и БД локализованы в РФ.
4. **Согласие 152-ФЗ:** Чекбокс обязателен для отправки формы, кликабельные ссылки открывают модальные окна с юридическим текстом.
5. **Cookie-баннер:** Уведомление с фиксацией согласия пользователя в LocalStorage.
